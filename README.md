# SkillForge AI

SkillForge AI is a personal skill-gap analysis and career preparation platform concept designed to help students prepare for specific job roles at different companies.

The idea is to allow users to:
- Select a target company and job role.
- Create a profile of their existing skills and proficiency levels.
- Compare their current skill set with the requirements of the selected role.
- Identify skill gaps and track their preparation progress.
- Get suggestions for relevant learning resources and role-specific mock assessments.

**Project Status:** Discontinued / Experimental

This repository represents an experimental project exploring personalised career preparation and skill-gap analysis. The initial implementation was not completed, and some planned features are not fully functional.
